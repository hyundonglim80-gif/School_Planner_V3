📌 프로그램 소개

         

이 프로그램은 선생님들의 학교 업무와 수업 일정을 한 곳에서 체계적으로 관리할 수 있게 도와주는 '개인 맞춤형 온라인 플래너'입니다. 입력하신 모든 내용은 구글 클라우드에 안전하게 자동 저장되어, 언제 어디서든 스마트폰이나 컴퓨터로 확인할 수 있습니다.

       
       
         

📅 화면 보기 방식 (상단 버튼)

         
               
  • 📝 (메모): 포스트잇처럼 할 일을 적어두고 완료 체크를 할 수 있는 공간입니다. 순서를 위아래로 끌어서(드래그) 바꿀 수도 있습니다.
    •            
  • 년 / 월 / 주 / 일: 달력의 형태를 조절합니다.              
                     
    • 년: 1년 치 주요 행사를 한눈에 봅니다.
      •                
    • 월: 한 달의 일정을 익숙한 달력 형태로 봅니다.
      •                
    • 주: 일주일 치 수업과 일정을 시간표 형태로 봅니다.
      •                
    • 일: 오늘 하루의 일정, 수업(메모, 준비물), 일지(사건, 감상 등)를 매우 상세하게 보고 꼼꼼하게 기록할 수 있습니다.
      •              
               
    •          
       
       
         

✏️ 뷰어 모드와 수정 모드

         

실수로 내용이 지워지는 것을 방지하기 위해 두 가지 모드로 나뉘어 있습니다.

         
               
  • 👁️ 뷰어 모드: 단순히 내용을 읽고 확인할 때 사용합니다. 글씨를 수정할 수 없도록 화면이 잠겨있습니다.
    •            
  • ✏️ 수정 모드: 일정을 적거나 고칠 때 [수정] 버튼을 누릅니다. 글씨를 고칠 수 있는 노란색 테두리 칸으로 바뀌며, 내용 입력 후에는 반드시 [💾 저장] 버튼을 눌러야 클라우드에 안전하게 저장됩니다! (저장하지 않고 이동하려 하면 경고창이 뜹니다.)
    •          
       
       
         

⚙️ 기타 유용한 기능 (⋮ 점 세 개 버튼)

         
               
  • 🗓️ 기준시간표 등록/적용: 학기 초에 매주 반복되는 기본 시간표(예: 월 1교시 국어, 2교시 수학...)를 미리 등록해 두고, 원하는 기간(예: 1학기 전체)에 한 번에 쫙 복사해 넣는 아주 편리한 자동화 기능입니다.
    •            
  • 📥 백업 및 업로드: 내가 쓴 데이터 전체를 엑셀(CSV) 파일로 내 컴퓨터에 다운받아 평생 보관하거나, 작성된 파일을 다시 프로그램으로 불러올 수 있습니다. (※ 일정에 '(휴일)' 또는 '(행사)'라고 쓰면 해당 일의 수업이 자동으로 지워집니다.)
    •            
  • 🔍 검색 기능 (단축키: /): 오래전에 쓴 내용이나 일지를 찾을 때 사용합니다. 검색 대상 기간을 정하고 '전체', '일정', '과목명' 등 여러 조건을 섞어서 매우 똑똑하게 찾아냅니다.
    •          
       
       
         

⌨️ 마우스 없이 빠르게! 단축키 안내

         

키보드를 활용하면 훨씬 빠르게 프로그램을 조작할 수 있습니다. (단, 글자를 입력하고 있을 때는 방향키 이동이 작동하지 않습니다.)

                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      
기능 동작단축키 (키보드)
이전 날짜로 이동Ctrl + ← (왼쪽 화살표)
다음 날짜로 이동Ctrl + → (오른쪽 화살표)
보기 형태 변경 (메모/년/월/주/일)Shift + ← 또는 →
오늘 날짜로 뿅! 돌아가기Ctrl + Spacebar (스페이스바)
👁️ 뷰어 모드로 변경 (읽기 전용)Ctrl + ↑ (위쪽 화살표)
✏️ 수정 모드로 변경 (글쓰기)Ctrl + ↓ (아래쪽 화살표)
💾 작성한 내용 클라우드에 저장Ctrl + Enter (엔터)
🔍 상세 검색창 바로 열기/ (슬래시)
열려있는 팝업/모달창 즉시 닫기Esc (이스케이프)
       
              
   
 

🏷️ 일정 라벨 관리

일정에 사용할 라벨을 정의합니다.
'수업 삭제'를 체크하면, 해당 라벨이 붙은 날은 시간표 일괄 적용 시 수업이 자동으로 비워집니다.
